Method & caveats — read before quoting any figure
  • Hallucination rate — denominator is every request that was not hold/analyze. An allowlist undercounted and once produced a rate above 100%.
  • Episodes vs raw count — a large gap means one agent reissued the same rejected request every step. That is a livelock, not many independent errors.
  • Stale context — detector replaced outright in 4c6897e. Figures are not comparable to runs 02–05.
  • Persona consistency — returns ~1.00 on about 99.8% of decisions. No discriminative power; not shown on this page.
  • Cross-run comparison — never compare a paired-harness result with an independent-arm result. Across seeds, report median and range; a single seed supports no rate claim.
  • Older logs — runs without a requested field cannot separate "asked to trade and was refused" from "held with a malformed field", and carry no disposition at all.
