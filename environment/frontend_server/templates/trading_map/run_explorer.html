What these numbers are not
read before quoting anything
Hallucination rate Denominator is trade_attempts — anything the model requested that was not hold/analyze. It counts requests, including clamped orders that still executed. An allowlist of buy/sell undercounted and once produced a rate above 100%.
Stale context Replaced outright in 4c6897e. Requires a superseded headline, the symbol named, and ≥2 distinctive tokens. The previous version scaled with reasoning length, so it measured verbosity. Figures here are not comparable to runs 02–05.
Persona consistency Returns ~1.00 on about 99.8% of decisions. It has essentially no discriminative power and is shown for completeness only. Do not read a result into this.
Episodes, raw vs distinct Reported both ways on purpose. A large gap means an agent reissued the same rejected request every step — a livelock, not many independent errors.
Cross-run comparison Never compare a paired-harness result with an independent-arm result: different populations, different denominators. Across seeds, report median and range — a single seed supports no rate claim.
hold is legal by construction An arm can improve its hallucination rate simply by trading less. Always read the rate next to trade attempts.
